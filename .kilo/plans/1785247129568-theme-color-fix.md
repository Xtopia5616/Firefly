# 主题色配置不生效修复计划

## 问题

用户修改 `src/config/siteConfig.ts` 中的 `themeColor.hue` 后，页面颜色不变，始终显示绿色（hue≈120）。

**根因**：`localStorage` 保存了之前通过设置面板自定义的 hue 值（如 120），而页面加载时始终优先读取 localStorage，忽略配置文件改动。

相关代码：
- `src/layouts/Layout.astro:294` — `const hue = localStorage.getItem("hue") || configHue;`
- `src/utils/setting-utils.ts:69-70` — `getHue()` 同样优先 localStorage
- `src/utils/setting-utils.ts:82` — `setHue()` 保存到 localStorage

## 修改方案

在 localStorage 中同时保存 hue 值和对应的 config 版本号（当前 config 的 hue）。页面加载时对比：若 config 已变化，则使用新 config 值并清除旧的 localStorage hue。

### 具体改动

#### 1. `src/utils/setting-utils.ts`

**`setHue()` 中同时保存 config hue 快照：**
```typescript
export function setHue(hue: number): void {
  if (...) return;
  localStorage.setItem("hue", String(hue));
  // 保存当前 config 的 hue 版本，用于检测配置变更
  const configCarrier = document.getElementById("config-carrier");
  if (configCarrier?.dataset.hue) {
    localStorage.setItem("configHueVersion", configCarrier.dataset.hue);
  }
  const r = document.querySelector(":root") as HTMLElement;
  if (!r) return;
  r.style.setProperty("--hue", String(hue));
}
```

**`getHue()` 中检测 config 是否已变更：**
```typescript
export function getHue(): number {
  if (typeof window === "undefined" || !window.localStorage) {
    return getDefaultHue();
  }
  const stored = localStorage.getItem("hue");
  if (stored === null) return getDefaultHue();

  // 检测 config 是否已变更
  const savedVersion = localStorage.getItem("configHueVersion");
  const currentVersion = String(getDefaultHue());
  if (savedVersion !== currentVersion) {
    // config 已变更，清除旧的 localStorage hue
    localStorage.removeItem("hue");
    localStorage.removeItem("configHueVersion");
    return getDefaultHue();
  }
  return Number.parseInt(stored, 10);
}
```

#### 2. `src/layouts/Layout.astro`

**更新 inline script（line 293-295），使用相同的 config 变更检测逻辑：**
```javascript
// Load the hue, detecting config changes
const savedConfigHue = localStorage.getItem("configHueVersion");
const hue = (savedConfigHue !== String(configHue))
  ? (localStorage.removeItem("hue"), localStorage.removeItem("configHueVersion"), configHue)
  : (localStorage.getItem("hue") || configHue);
document.documentElement.style.setProperty("--hue", hue);
```

或者更可读的写法：
```javascript
const savedConfigHue = localStorage.getItem("configHueVersion");
let hue;
if (savedConfigHue !== String(configHue)) {
  localStorage.removeItem("hue");
  localStorage.removeItem("configHueVersion");
  hue = configHue;
} else {
  hue = localStorage.getItem("hue") || configHue;
}
document.documentElement.style.setProperty("--hue", hue);
```

## 效果

- 修改 `siteConfig.ts` 的 `themeColor.hue` → 页面下次刷新立即生效
- 通过设置面板自定义 hue → 刷新后依然保持
- 修改 config 后 → 之前保存在 localStorage 的自定义 hue 自动失效，config 新值生效
- 未修改 config 时 → 先前自定义的 hue 继续保留

## 验证方式

1. 修改 `src/config/siteConfig.ts` 中 `themeColor.hue` 为各值（如 0/红、120/绿、250/蓝紫），运行 `pnpm dev`
2. 打开浏览器，确认页面主题色随配置变化
3. 通过设置面板切换色相，刷新页面，确认自定义值保持
4. 再次修改 config 的 hue，刷新页面，确认 config 新值生效
